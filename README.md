# pawlaris-legal

Pawlaris iOS app 的產品頁與法律文件，以 GitHub Pages 發布，自訂網域 `pawlaris.sentiralabs.app`。
舊網址 `https://teccat.github.io/pawlaris-legal/*` 由 GitHub 自動 301 到新網域的同一路徑。

- 產品頁（英文）：https://pawlaris.sentiralabs.app/ ・ 繁中：https://pawlaris.sentiralabs.app/zh/
- 隱私政策：https://pawlaris.sentiralabs.app/privacy/ ・ 繁中：https://pawlaris.sentiralabs.app/zh/privacy/
- 支援：https://pawlaris.sentiralabs.app/support/ ・ 繁中：https://pawlaris.sentiralabs.app/zh/support/
- 使用條款：Apple 標準 EULA（https://www.apple.com/legal/internet-services/itunes/dev/stdeula/）
- 公司首頁：https://www.sentiralabs.app/（原始碼在 `TecCat/ikima` 的 `company/`）

`/en/` 是轉址頁（舊的英文版網址），導回 `/`。隱私政策與支援頁的中文版在 `/zh/privacy/`、`/zh/support/`（`zh/*.md`）。

修改 `privacy.md` 時，請同步更新生效日期，以及 app repo 內的副本 `docs/legal/privacy-policy.md`。
